# Медиатор

Стартовая инфраструктура одностраничного сайта юридического агентства «Медиатор». Сейчас приложение содержит только технический каркас; дизайн и секции будут добавлены по предоставленному макету.

## Стек

React, TypeScript, Vite, SCSS, lucide-react.

## Запуск

```bash
npm install
npm run dev
```

Production сборка: `npm run build`. Проверка стиля кода: `npm run lint`.

## Структура

- `src/components/` — компоненты секций сайта
- `src/assets/` — изображения, иконки и брендовые материалы
- `src/data/` — контент и данные
- `src/hooks/` — React hooks
- `src/styles/` — базовые SCSS переменные, миксины и глобальные стили
- `src/types/` — общие TypeScript-типы
- `docs/` — дизайн-бриф и подтвержденный контент

Подробные правила проекта — в [AGENTS.md](./AGENTS.md).
