# Дизайн-бриф

## Визуальный reference

Главный источник — предоставленный макет сайта для desktop (1440 px), tablet (768 px) и mobile (375 px). Ссылка на старый сайт `https://mediatorau.tilda.ws/` — только вторичный источник контекста; его контакты и устаревающий текст не переносить без подтверждения.

## Направление

- Теплый кремовый фон, мягкие бежевые оттенки и терракотовый фирменный акцент.
- Темно-коричневый или почти черный основной текст.
- Много свободного пространства и аккуратная editorial типографика.
- Крупные заголовки с serif-гарнитурой; sans-serif для интерфейса и основного текста.
- Тонкие границы, минимальные тени, умеренные скругления и спокойный premium legal стиль.
- Для текущего макета использованы временные фотографии в палитре референса; они подготовлены как отдельные заменяемые WebP assets.
- Интерфейс использует семейства Playfair Display для заголовков и Inter для текста.
- Header, hero, преимущества, карточки услуг, шаги работы, описание агентства, блок руководителя и footer следуют композиции макета. FAQ и форма включены по брифу.

## Не использовать

Вид типичного AI-generated landing page, конструктора, инфобизнеса, личного блога, сайта одного юриста, банковского корпоративного сайта или перегруженного SaaS dashboard.

## Адаптивность и доступность

Проектировать для desktop, tablet и mobile. Использовать семантическую разметку, видимые focus states и доступные подписи интерактивных элементов.
